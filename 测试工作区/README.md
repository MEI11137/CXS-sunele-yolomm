# 测试工作区

这个目录是给**评委账号**做真实巡检用的业务工作区骨架，不是源码根目录，也不是服务的私有数据目录。

```
测试工作区/
├── 数据集/   放 YOLO 目录（images/ labels/ data.yaml）或待导入的图片集
├── 权重/     放 .pt 权重（单模态或双模态）
└── 输出/     放导出的识别记录、回流数据集 ZIP、训练产物等
```

## 怎么用

1. 先启动后端并登录管理员账号，把这个**具体目录**（例如 `D:\Haixun\测试工作区`）授权给评委账号：

   ```powershell
   .venv\Scripts\python -m backend.cli add-root "D:\Haixun\测试工作区" --label '评委巡检工作区' --grant-to judge
   ```

2. 评委账号在网站里新建项目，并把项目文件夹绑定到该目录下的子目录（或该目录本身）。
3. 数据集/权重通过页面上传，或放进上面对应的子目录后从「工作区文件夹」导入。

**不要把整个源码根目录或磁盘根目录授权出去**：那会让账号能看到源码、`var/` 里的数据库与密钥、
以及其他项目的文件。只授权这个工作区目录。

## 与私有数据区的区别

| 内容 | 位置 | 能否给评委看 |
| --- | --- | --- |
| 数据集、权重、导出产物 | 本目录 | 能（业务材料） |
| 数据库 `haixun.db`、`secrets/`（连接密钥密文）、运行记录 | 部署时指定的 data-dir（默认 `var/…`） | **不能** |
| 源码、`.tunnel-token`、模型 API Key | 源码目录 / 本机私有配置 | **不能** |

## Git 说明

本目录只跟踪 `.gitkeep` 与这三个 `README.md`，真实数据、权重和产物一律被 `.gitignore` 忽略：
`git clone` 后能看到目录结构，但不会把几百 MB 的图片、`.pt` 或训练输出带进仓库。
