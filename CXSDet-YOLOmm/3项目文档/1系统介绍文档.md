# 基于「YOLO目标检测 + 多模态AI分析」的光伏板缺陷检测分析系统

## 项目概述

本项目是一个基于人工智能技术的光伏板（太阳能板）缺陷检测系统，旨在通过先进的计算机视觉技术和深度学习模型，为光伏发电行业提供智能化的光伏板质量检测服务。系统集成了图片检测、视频检测、实时检测、模型训练、数据集管理等多项功能，构建了一个完整的光伏板缺陷检测服务平台。

### 核心创新点

1. **多类型缺陷检测**: 支持4种常见光伏板缺陷的智能识别和分类
2. **多模态检测方式**: 支持图片、视频、实时摄像头三种检测模式
3. **YOLO模型集成**: 集成YOLOv8/YOLO11/YOLO12等先进目标检测模型
4. **智能检测分析**: 基于AI的光伏板缺陷自动识别和定位
5. **分层权限管理**: 支持管理员和普通用户的差异化功能访问
6. **完整工作流程**: 从数据集管理到模型训练再到缺陷检测的完整闭环
7. **多模态大模型辅助分析**: 使用多模态大模型根据YOLO检测识别结果和图片进一步分析并给出合理建议(属于图片识别功能模块)

### 应用场景

- **光伏电站**: 光伏板运维的质量检测和缺陷识别
- **新能源企业**: 专业的光伏板质量检测服务
- **运维公司**: 光伏电站的缺陷分析和效率优化
- **教育培训**: 光伏发电技术和缺陷检测的教学演示

## 技术架构

### 整体架构设计

系统采用前后端分离架构设计，分为前端展示层、后端业务层、算法服务层和文件存储层四个主要部分：

```
┌─────────────────┐    ┌─────────────────┐
│   前端层 (Vue3)  │────│  后端层 (Flask)  │
│   Port: 3000    │    │   Port: 5000    │
│  光伏板检测管理UI │    │  业务逻辑处理     │
│  检测结果展示     │    │  AI检测引擎      │
└─────────────────┘    └─────────────────┘
                                │
                       ┌─────────────────┐    ┌─────────────────┐
                       │  文件服务层       │    │   数据库层       │
                       │   Port: 5000    │    │   SQLite 3      │
                       │  图片视频存储     │    │  检测记录数据     │
                       └─────────────────┘    └─────────────────┘
```

### 2. 光伏板缺陷检测系统

#### 支持的缺陷类型
系统支持4种常见光伏板缺陷的检测：

1. **bird_shit** - 鸟粪：光伏板表面的鸟类粪便污染
2. **crack** - 裂纹：光伏板表面的裂纹损伤
3. **dirt** - 污垢：光伏板表面的灰尘、污渍等污染物
4. **panel** - 面板：光伏板面板区域

#### 检测精度指标
基于训练好的模型在测试集上的表现：
- **整体精度**: Precision = 0.565, Recall = 0.579, mAP50 = 0.539, mAP50-95 = 0.352
- **各类别精度**:
  - bird_shit (鸟粪): Precision = 0.256, Recall = 0.263, mAP50 = 0.172, mAP50-95 = 0.077
  - crack (裂纹): Precision = 0.685, Recall = 0.827, mAP50 = 0.773, mAP50-95 = 0.396
  - dirt (污垢): Precision = 0.596, Recall = 0.412, mAP50 = 0.428, mAP50-95 = 0.288
  - panel (面板): Precision = 0.724, Recall = 0.813, mAP50 = 0.784, mAP50-95 = 0.647

### 3. 多模态检测方式

#### 图片检测 (Image Detection)
- **功能特性**: 上传光伏板图片进行缺陷检测
- **支持格式**: JPG, PNG等
- **检测流程**: 图片上传 → AI分析 → 结果展示

#### 视频检测 (Video Detection)
- **功能特性**: 处理光伏板检测视频进行缺陷分析
- **支持格式**: MP4, MOV等
- **处理流程**: 视频上传 → 帧提取 → 逐帧检测 → 结果合成
- **进度跟踪**: 实时显示处理进度和状态

#### 实时检测 (Realtime Detection)
- **功能特性**: 连接摄像头进行实时光伏板缺陷检测
- **实时处理**: 200ms间隔的连续检测
- **目标跟踪**: 基于ByteTrack的目标跟踪算法
- **会话管理**: 检测会话的创建、管理和记录

### 4. 数据集管理系统

#### 数据集信息
- **数据集来源**: 光伏板缺陷检测专用数据集
- **数据规模**: 总计3276张光伏板图片
  - 训练集：2620张图片
  - 验证集：328张图片
  - 测试集：328张图片
- **数据格式**: 支持ZIP压缩包上传
- **标注格式**: YOLO格式的边界框标注

#### 数据集管理功能
- **数据集上传**: 支持ZIP格式数据集文件上传
- **数据验证**: 自动验证数据集格式和完整性
- **状态管理**: 待验证/验证通过/验证失败三种状态
- **结构信息**: 自动提取数据集结构信息

### 5. 模型管理系统

#### 支持的模型类型
- **YOLOv8**: yolov8n.pt (轻量级模型)
- **YOLO11**: yolo11n.pt (最新版本)
- **YOLO12**: yolo12n.pt (最新版本)

#### 模型管理功能
- **模型配置**: 训练参数设置（epochs, batch_size等）
- **训练状态**: 训练中/完成/失败/已发布/终止

### 6. 检测记录管理

#### 记录类型
- **图片检测记录**: 存储图片检测的历史记录
- **视频检测记录**: 存储视频检测的处理记录
- **实时检测记录**: 存储实时检测的会话记录

#### 记录内容
- **检测信息**: 检测时间、使用模型、置信度阈值
- **结果数据**: 缺陷类别、位置坐标、置信度分数
- **文件存储**: 原始图片/视频和结果图片/视频
- **用户信息**: 检测用户、权限控制

## 数据库设计详解

### 核心数据表关系图

```
用户表(user) ──┐
              ├── 数据集表(dataset)
              ├── 模型表(models)
              ├── 图片检测记录表(detection_records)
              ├── 视频检测记录表(video_detection_records)
              └── 实时检测记录表(realtime_detection_records)
```

### 数据表详细设计

#### 1. 用户表 (user)
存储系统用户的基本信息和权限设置：
- **主键**: id (自增长)
- **唯一约束**: username (确保用户名唯一)
- **角色控制**: role字段区分管理员和普通用户
- **状态管理**: status字段控制用户启用/禁用
- **文件存储**: 头像使用bucket+object_key模式存储

#### 2. 数据集表 (dataset)
管理光伏板缺陷检测数据集：
- **主键**: id (自增长)
- **基本信息**: 名称、描述、文件大小等
- **文件信息**: ZIP文件存储路径
- **状态管理**: 验证状态和验证结果
- **结构信息**: 数据集结构JSON信息

#### 3. 模型表 (models)
管理YOLO检测模型：
- **主键**: id (自增长)
- **模型信息**: 名称、描述、基础模型类型
- **训练参数**: epochs、batch_size等
- **训练状态**: 训练进度和结果
- **模型文件**: 训练完成的模型权重文件

#### 4. 检测记录表
存储各种检测记录：
- **图片检测记录**: detection_records表
- **视频检测记录**: video_detection_records表
- **实时检测记录**: realtime_detection_records表
