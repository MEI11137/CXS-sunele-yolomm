## 必查的假功能类型

- 点击无响应、只改按钮／计数、占位弹窗、空 handler、`href=#`、永远 disabled 却没有原因。
- 显示成功但没有请求、后端没修改、文件没生成／更新、刷新后丢失。
- 单条按钮处理全部、批量只处理第一条、选择范围丢失、筛选与导出范围不符。
- UI 勾选没有传到 Agent，Agent 只能看到列表、猜用户指向或要求复制 ID。
- Agent 宣称导航／执行成功，但实际页面、目标记录、状态和结果不符。
- 单模态界面错误要求配图；双模态缺少辅图编辑、辅图标注丢失。
- 删除／恢复只改本地显示，重复点击创建重复对象；取消操作仍继续执行或假释放资源。
- 控件只在管理员可用，普通评委看到相同入口却没有有效能力或错误说明。
- 返回页面后丢筛选、页码、所选范围、草稿或输入；重复上传／重复请求无提示。
- 操作列错位、菜单被裁切、窄业务区主要按钮不可达、弹窗遮挡、复选框缺少可访问名称。
