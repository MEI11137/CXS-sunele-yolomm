# 会话字号（使用与验收说明）

> 面向使用与复核：这是一个**只影响对话阅读**的本地外观偏好，不涉及权限、账号数据或后端接口。

## 入口与行为

- 位置：**设置 → 账号与外观 → 外观 → 会话字号**。普通账号即可使用，不需要管理员权限，也不调用后端。
- 取值：**12–24 px，步长 1，默认 14 px**（可精确选 17 px）；旁边「恢复默认」回到 14 px。
- 范围：**仅对话正文与输入区**——主项目聊天与业务页右侧助手的用户消息、助手已保存正文、流式正文、输入框，以及其中的标题/列表/引用/表格/代码块。
- 不影响：左侧导航、业务表格、按钮、工具卡元数据；资料/手册等非会话 Markdown 仍是标题 14 px、表格与代码 12 px。
- 保存：只写本机 `localStorage`（键 `hx17-chat-font-size`），**不进服务器、不进账号、不清理其它偏好**；换浏览器/换机器不会跟随。
- 容错：空值、非数字、越界值都收敛到合法范围（默认 14，越界取最近边界，非整数四舍五入）；浏览器禁用存储时按默认值运行、切换字号仅本次生效，页面不报错。侧栏排序、当前项目、复核草稿等**其它**模块仍直接使用 `localStorage`，不在本次容错范围。

## 实现要点

- `frontend/src/stores/ui.ts`：`chatFontSize` + `setChatFontSize / resetChatFontSize`，把值写成 CSS 变量 `--chat-font-size`；与主题、助手宽度共用同一套本地读写 helper。
- `frontend/src/components/ChatFontSizeField.vue`：原生 `select` + 恢复默认 + 提示 + 即时预览（设置页与 QA fixture 复用同一组件）。
- `frontend/src/styles.css`：`.message-text` / `.composer-textarea` 使用该变量；Markdown 覆盖**只**挂在 `.message-text.markdown-body` 上，代码与表格按 `calc(var(--chat-font-size) * 12 / 14)` 缩放（默认仍是 12 px），不叠加 `em`。
