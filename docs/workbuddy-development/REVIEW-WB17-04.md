## 独立发现并由 WorkBuddy 修复的问题

- 复核 GET 返回裸状态，前端却读取 `data.state`：真实普通账号页面加载失败。统一接口包装，并增加真实 TypeScript 适配器调用 HTTP 的回归。
- 拖角点没有目标框索引，移动分支不会执行；空白拖拽会隐式新增框。修复实际事件链，显式区分选择、平移与画框。
- 历史样本新增指纹列为 NULL，导致完全相同的原图被判为新图。共享身份读取从授权目录真实文件补足依据。
- 仅来源键相同被当成强匹配，可能覆盖不同图片。现在只有内容一致才能自动匹配，弱候选需明确处理；不相容尺寸不能静默套用标注。
- 用大小和时间戳直接信任缓存。独立等长 PNG 加保留 mtime 反例证明错误，修复后每次核验实际字节哈希；内容一致时复用像素指纹以免重复解码。
- 修改回流表单仍可执行旧草稿。前端比较提交快照、禁用过期预览；服务端定稿重新校验真实计划与来源状态。
- 先前反例还覆盖了旧确认在驳回后被误用、草稿并发覆盖、错误模态目录、同图跨划分、零比例分配、输出文件名越界、未审核权重模块等，修复未回退。
