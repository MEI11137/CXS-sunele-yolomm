## 2. 实际改动要点

### 2.1 主题与尺寸（`styles.css`）

- 顶部变量换成 v1.6 `theme.css` 的固定色值：浅色 `#f3f5f7 / #ffffff / #17212a / #1d5fbf`，
  深色 `#111111 / #1b1b1b / #f1f1f1 / #6da4f5`；不再是原来的蓝灰 `#f6f7f9 / #2563eb`。
- 旧变量一次性映射，组件不用逐个改名：
  `--panel-soft → --panel-secondary`、`--border-strong → --border-control`、
  `--accent-soft → color-mix(accent 10%, panel)`、`--danger-soft → --danger-bg`、
  `--ok → --success`、`--radius → 8px`、`--shadow → --shadow-sm`。
- 字体栈/正文 14px、按钮 32px·13px·6px 圆角、主按钮改用 `--btn-primary`（浅色深底白字、
  深色白底深字）、侧栏 `--nav-w: 216px`、助手 `--assistant-w: 336px`、内容边距 24px。
- **修掉未定义变量**：`DocumentsPanel`、`TrainingPanel`、`McpPanel` 三处
  `background: var(--surface-2, #f5f6f8)` —— 这个变量从来没有定义过，深色下就是
  “白底 + 浅字”（文档正文、训练日志、MCP 调用结果都中招）。统一改成 `var(--panel-secondary)`。
- 两个根节点加 `color-scheme: light|dark`，原生 `select`/下拉/滚动条跟随主题；
  助手底部的权限/模型选择原来是无样式原生控件，深色下是白框，现补 `select` 基础样式。

### 2.2 外壳与顶部导航（`layouts/AppLayout.vue`）

- 结构改成 v1.6 的 flex：`左侧栏 + 项目主体（顶部工具栏 + 内容行）`，不再用三列 grid 写死宽度。
- 项目顶部：项目名 + 目录（未绑定就写“项目文件夹尚未绑定”）+“项目详情”+ **唯一一套**业务导航
  （项目对话/图片巡检/识别记录/人工复核队列/数据回流/数据集/模型）。
- 右侧助手：默认 336，可拖 260–640，双击恢复；收起后右侧留“助手”竖条入口。
- 移除 `SessionView` 页内的业务按钮行（原来和侧栏各有一套，属于重复导航）。

### 2.3 左侧（`components/SidebarNav.vue` 重写）

只保留：品牌、**新建项目**、搜索、项目/会话树、底部回收站/设置/本机管理/账号。

- 删掉每个项目下面重复的“业务”链接组；`BUSINESS_PAGES` 现在只在顶部渲染一次。
- 项目行显示会话数，展开后是历史会话，当前项目/当前会话高亮；搜索同时匹配项目名与会话标题。
- 主题开关从侧栏移到「设置 → 外观」（v1.6 侧栏本来就没有这个入口，避免侧栏多一项）。

### 2.4 项目入口与详情

- `/projects`：欢迎页（三步说明 + 新建项目 + 检查模型连接），不再铺一屏项目管理卡片。
- `/projects/:id`：**直接进主对话**。已有会话就 `replace` 到最近一条；没有会话就停在空输入区。
- `AssistantPanel` 支持“无会话直接开口”：`ensureSession()` 在**用户点发送时**才建会话
  （标题取前 24 字），刷新不会凭空造会话。
- 目录绑定、项目要求、改名、删除、会话改名/删除 → `ProjectDetailsDrawer`（顶部“项目详情”，
  地址带 `?details=1`，关闭时清掉），全部手动入口保留。

### 6.1 新建项目必须能指定项目文件夹

**问题**：上一版 `NewProjectDialog` 只有名称和说明，注释还写着“v1.6 不在新建时选目录”——
这句话是错的。v1.6 `WorkspaceSwitcher` 的实际设计就是建项目时选文件夹；对第一次用的人，
“我的文件在哪”正是第一步，不能以“简化”为名藏进详情抽屉。

**改法**：

- 弹窗主字段改为 **项目名称 + 项目文件夹**；文件夹可手填，也可用既有 `DirectoryBrowser`
  浏览（复用 `/directories/browse` 与 `PUT /projects/:id/root`，**没有**新增全盘浏览或扩权）。
- 说明改为「+ 添加说明（可选）」折叠项。
- 目录为空也允许创建，但字段下方写明“不绑定文件夹时**不能读写本地项目文件**，可稍后绑定”，
  不宣称已获得文件权限。
- 填了目录：先创建、再绑定，**绑定成功后才跳转**；绑定失败停在弹窗、显示后端原话，
  按钮变成“重试绑定并进入”。项目 ID 已记下，重试只重绑，**不会重复建同名项目**。
- 弹窗内已展示的错误不再让顶部横幅重复刷一遍（`workspace.error` 读完即清）。
- 项目详情抽屉里的重新绑定/解绑与替换确认保持原样。

### 6.2 恢复 v1.6 的六项项目导航

**问题**：上一版顶栏是七项（把“数据回流”也放上去了），名称与顺序也和 v1.6 不一致。

**改法**：`lib/layout.ts` 的 `BUSINESS_PAGES` 按 v1.6 `utils/projectRoutes.ts` 恢复为
**项目对话｜人工复核｜数据集｜模型管理｜图片巡检｜识别记录**（共六项）。

- 数据回流**没有删**：路由、页面、接口、Agent 工具全部保留，入口改到「数据集」页头部
  （“数据回流”按钮，草稿行里的“去修改”也仍在）。
- 新增 `navOwner()` 统一高亮归属：`reflow → 数据集`、`review（单条复核）→ 人工复核`，
  顶栏不再为回流多开第七个入口。
- `tests/layout.test.ts` 同步更新：断言六项的顺序与中文名，并断言 `reflow` 不在顶栏。
