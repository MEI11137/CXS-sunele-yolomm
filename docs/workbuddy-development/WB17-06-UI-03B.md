## 2. 关键决策

- **训练设备不再写死 CPU**：`TrainingPanel.params()` 原来硬编码 `device:'cpu'`。现在
  页面从 `GET .../training/devices` 读真实探测（cuda_available/cuda_count/detail），
  无 CUDA 时 GPU 选项标注真实原因（如 `cuda_available=False, device_count=0`）但保留
  可选——选择后「校验参数」由后端 plan 的设备探针给出 `TRAINING_DEVICE_UNAVAILABLE`
  真实错误。测试机的“本机无 GPU”不进产品文案。
- **加入反馈数量真实**：勾选后工具栏显示「可反馈 M 条」（仅人工已确认），后端
  `REVIEW_REQUIRED` 强制不变；未确认的行菜单项禁用并给原因。
- **批量核查失败如实**：模型未过图像能力验证时横幅如实报错（探针里真实出现），不吞所选 ID。
- **CSV**：走共享 `detections/export`（scope=page/selected + 真实 ID 列表），不造前端假 CSV。
