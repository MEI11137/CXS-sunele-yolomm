## 1. 行为

- 同一 **项目 + 所有者** 内，内容/模态/类别/标注/划分相同的有效数据集重复导入 → **复用已有**，
  返回 `{...dataset, reused: true}`，不建第二份记录。
- 指纹只取实际内容：每样本 `split + sha256 + pixel_sha256 + X图字节摘要 + boxes + class_ids`，
  外加 `modalities / secondary / classes`；**排序后**哈希，忽略显示名称、压缩包时间戳与顺序、
  源绝对路径、随机目标 ID。
- 改标注、改划分、换 X 配图、改类别/模态 → 指纹不同 → 各自建库。
- 回收站（`deleted_at` 非空）不参与匹配，也不复活；导入照常新建。
- 旧记录（`content_fingerprint` 为空）用已落库样本重算指纹参与比较，命中即**补齐**列；
  X 图读不到就放弃比较（不猜）。

## 2. 并发与清理

- 迁移 **v18** 加 `datasets.content_fingerprint`，**v19** 建部分唯一索引
  `(project_id, owner_id, content_fingerprint) WHERE content_fingerprint IS NOT NULL AND deleted_at IS NULL`。
  并发靠这条约束决出唯一赢家，不是“先 SELECT 再 INSERT”。
- 输掉竞争/命中复用的一方，只 `storage.remove_tree(root, base)` 清理**本次自己创建**的副本目录，
  不删已有数据集、不动原输入；清理仍走 storage 守卫。
