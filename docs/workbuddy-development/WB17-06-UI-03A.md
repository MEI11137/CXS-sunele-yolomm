## 2. 本轮根因与修复：菜单动作拿到 null

独立核验反例（root，`UI-03A独立页面核验.json`）：点「移入回收站」**没有发出删除请求**，
pageerror=`Cannot read properties of null (reading 'name')`，列表行数不变。

根因：模板写的是

```
@click="hideMenus(); removeDataset(menuFor)"
```

`hideMenus()` 先把 `menuFor.value` 置 null，第二个参数（`menuFor` 的内联读取）就成了
null——`removeDataset` 里读 `dataset.name` 抛 TypeError，请求静默失败。同样的
`resplit(menuFor.id)` / `restoreDataset(menuFor)` 三处同根因。

修复（`DatasetsView.vue`）：新增共享动作处理 `withMenuTarget`——先把 `menuFor.value`
快照到局部变量，再关菜单，最后用快照调用动作：

```ts
function withMenuTarget(action: (dataset: DatasetSummary) => void): void {
  const target = menuFor.value
  hideMenus()
  if (target) action(target)
}
```

三处模板改为 `@click="withMenuTarget((item) => resplit(item.id))"`、
`withMenuTarget(removeDataset)`、`withMenuTarget(restoreDataset)`。
「导出 ZIP」是 `<a :href=...>`，href 在渲染时已绑定，不受影响。
危险确认（`window.confirm`）、请求失败提示（`errorMessage` → `business.error`）、
移入回收站不删文件（软删除 `deleted_at`）的语义全部保留，未动后端。
