# 海巡智检参赛作品大纲

**光伏多模态巡检与数据优化智能体**

## 一 作品定位与核心问题

**作品名称：** 海巡智检。所选赛道：赛道四 AI+主办大学自定义。

**应用方向：** 面向新能源与电气工程实践教学、光伏运维场景，提供对话驱动的巡检与训练数据质量优化工作台。

**核心问题：** 光伏巡检中，误报漏报与标注偏差难以及时回流，数据整理和复核操作分散。海巡智检通过对话调度多模态检测与AI核查，将人工确认的标注回流为可追溯的数据版本，为YOLO模型优化提供可靠输入。

## 二 智能体功能模块

| 功能模块 | 主要功能 |
| --- | --- |
| 项目与资料 | 查找授权目录中的图片、数据集和权重；检索项目资料并定位原文。 |
| 检测与AI核查 | 按置信度运行YOLO；结合真实RGB与红外配图提示误报、漏报疑点。 |
| 人工复核与回流 | 双画布编辑（RGB参考、IR副模态或单画布）；确认后回原集生成修订版，已有图替换旧标注、新图新增，原版保留，或另建数据集。 |
| 训练与模型管理 | 配置训练参数、查看训练状态与模型对比、发布模型；GPU训练另在服务器验收。 |
| 对话与任务执行 | 调用真实业务与文件工具，保存会话与结果；选中记录可附给助手。 |

**知识与资料来源：** 内置的数据整理、多模态配对、复核回流等任务手册；用户授权上传的PDF、Word项目资料；通过工具实时读取的数据集说明、模型及检测记录。资料按项目授权使用，回答可追溯到原文或业务对象。

**实现基础：** 复用YOLO检测模型与开源Agent执行框架（含OpenCode引擎），围绕光伏场景实现业务工具适配、项目交互与数据追溯；第三方来源与许可声明保留。

## 三 核心交互流程

对话明确材料与参数 → 检查项目数据与权重 → 批量检测与AI核查
人工双画布复核并确认 → 指定回流去向，生成修订版或新数据集
按需训练与对比 → 由用户指令发布模型

AI负责提示疑点，人工对最终标注负责；其余操作按所选权限模式和明确指令执行，原有手动操作入口继续保留。

## 人工复核与数据回流实测

### 场景三 双画布人工复核与标注修正

**提示词：** 打开这条检测记录的人工复核界面，我对照RGB与红外热成像检查检测框、类别和严重程度；最终标注由我确认提交。

**对应输出：** 同一记录以RGB为参考模态（1280×1024，3个框）、红外为副模态（0框，可继续编辑）双画布打开；支持缩放、画框、改类别、确认无缺陷或提交；人工提交后保存该次复核版本，AI建议与人工结论分开记录。

**提示词：** 把已确认的复核结果回流：修改过的样本回原数据集生成修订版，新样本另建数据集；原版本保留，暂不训练。

**对应输出：** 数据集页新增“回流新建”的1样本RGB数据集与“回流修订”的5样本版本（原4样本，追加1张），原项目数据集仍在；回流草稿与生成历史3条，标签、清单可追溯，未启动训练。
