# INT-32：执行确认固定在输入框上方

- 日期：2026-10-28；实施工具：Codex；分支：`feature/opencode-agent`。
- 用户要求：确认执行窗口放在对话输入框上方，避免被 Agent 连续输出推到历史消息上方。

## 实现

- `AssistantPanel.vue` 在消息滚动容器外、输入框前增加确认栏宿主；主对话、业务页面侧栏和移动面板共用。
- `AgentProgress.vue` 通过 Vue Teleport 将原有待批准卡和整轮计划确认移到宿主。保留原来的单一任务轮询、业务接口、动作ID/版本检查与审批规则，不新增执行链路。
- 同时有多张待确认卡时显示当前位置及上一项/下一项，只展示当前一张；刷新任务状态保持当前选择，批准/拒绝后移除已处理卡，全部处理完后确认栏无空白占位。
- 预览默认收起；固定栏高度受限，长摘要与预览在卡片内滚动，批准/拒绝按钮和下方输入框仍可见。执行历史仍在消息列表中。
- 确认失败在固定卡片中显示；操作错误与轮询错误分开保存，不会因下一次成功轮询立即消失。切换会话/项目清理旧卡片和错误；异步确认回包使用 generation 校验，不能修改另一个会话的忙碌状态或显示错误。
- 扩展已有 `tests/chat-ui.ts` 隔离验收页，模拟三张审批卡、审批失败、计划确认、会话切换和操作调用记录。模拟接口不访问真实业务库或模型API。
