## 部署边界与后续验收

1. 正常开发前端在 `web-haixun`，不是 `web-vue`；默认代理后端 5020。
2. 使用原来已能运行 YOLO 的 Python 环境，补装 `requirements-agent.txt`。本机现用 `pvdetect` 已补装；其他协作者需各自安装。
3. 重启原开发后端以加载新路由/迁移；前端 `npm run dev`。同一数据库只允许一个后端进程。
4. 在设置中连接本人的模型，检查聊天、视觉和工具能力。DeepSeek 的文本连接认证成功不代表它能理解图片；以网站能力检查为准。

6. 原有视频/实时功能保留；本轮不扩展对应 Agent 流程，也不宣称补齐了本机视频编码器。
7. 新前端提供权重导入与增量训练；初始训练原后端入口保留，没有新增另一套初始训练向导。
8. MCP 本机服务不是网站 OS 沙箱；只连接自己核对过、已正确限定目录的服务。OAuth 与旧 SSE-only 客户端不在本次交付范围。
