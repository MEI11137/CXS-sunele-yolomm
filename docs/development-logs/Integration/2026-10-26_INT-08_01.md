## 1. 附件：File 本体与资源引用（13.1）

- `Attachment` 类型增加 `file / fileId / resourceId / error`，`state` 改为 `selected|uploading|uploaded|failed`。
- 选择/拖拽/粘贴后**立即上传并登记资源**：`uploadProjectFile` → `registerResource({kind, displayName, metadata:{file_id}})`，拿到 Agent 资源 id。
- 上传失败保留 File，列表显示原因并提供「重试」；有未完成上传时禁止发送。
- `sendMessage` 契约改为 `sendMessage(sessionId, text, { resourceRefs, onDelta, signal })`，
  正文**不再拼文件名**；只有纯附件时发送一句明确指令「请查看我上传的附件。」。
- 附件以 `resource_refs: [{id}]` 提交，后端按资源解析；前端只回显附件名。
- `stop()` 现在同时 `abort` 前端等待并调用 `stopTask`，不再"点了停止但其实没停"。

## 2. 图片巡检：真实上传、真实规划、真实执行（13.2）

- `ImageItem` 保留 `file`，选择后立即上传；页面显示「上传中/已上传/上传失败」与项目引用状态。
- 补 **RGB + X** 配对输入：每张影像可「附带 X 影像」，`detectImage` 以 `x_image` 字段提交；
  接受格式与后端 `allowed_extensions` 对齐（jpg/jpeg/png/webp/bmp/gif），前后端不再各说一套。
- 模型选择只列**可用**模型（`status==='available'`），没有时明确提示"仅已发布模型可执行检测"。
- 新增置信度阈值控件（0.05–0.95），真实传给后端。
- 两条真实入口，都不绕过确认：
  1. **由助手规划**：创建真实会话（不再写死 `session_id`）→ 发带 `resource_refs` 的检测指令 → 取 `turn.task` / `turn.action` 显示计划卡与动作卡；
  2. **直接检测**：用户已明确指定模型与影像后的立即执行，逐张调用 `/api/detection/detect` 真实推理并落库。
- 删除 `confirmRun` 的 sleep 假完成，改为：
  `confirmPlan(taskId)` → 若返回待确认动作则 `confirmAction(actionId, revision)` → `getTaskSnapshot` 轮询，
  **只有后端返回 `completed` 才显示完成**；`failed/partial_failed/stopped/interrupted` 分别如实展示；
  超时明确提示"任务可能仍在后端执行"。
- 「取消当前步骤」「拒绝」都改为真实 `stopTask` / `rejectAction`，不再只改内存。

## 3. 人工复核：真实原图、动态类别、真实提交（13.3）

- 数据源改为 `listRecords` 的真实记录（含 `detections / review_version / corrected_annotations`），
  不再使用 `inspection.defects` 的简化映射，也不再按 `turbineId` 取本地演示图。
- 原图/结果图走**受保护文件**：把后端返回的绝对 URL 归一化成同源 `/api/file/...`，靠登录时下发的
  `cxs_file_session` cookie 鉴权（`<img>` 无法带 Bearer 头，这一点在 INT-07 已确认）。
- **三套坐标显式区分**（本轮最重要的坑）：

  | 来源 | 坐标系 |
  | --- | --- |
  | `detection_result[].bbox` | `[x1,y1,x2,y2]` **像素坐标**（实测 255.1, 388.8, 1063.1, 651.2） |
  | `human-review` 的 `annotations[].bbox` | `[x1,y1,x2,y2]` **0-1 归一化**（`review_service._validate_annotations` 强校验） |
  | 画布本地 `BoundingBox` | 左上角 + 宽高，0-1 归一化 |

  读检测框时先量原图 `naturalWidth/Height` 再做像素→归一化；提交时把宽高加回右下角（`xywh → xyxy`）。
  之前直接把像素坐标当归一化，框全部落在画布外面（第一版截图里"一个框都看不到"就是这个原因）。
- 类别下拉改为 `listCategories()` 的真实类别表（鸟粪/裂纹/污垢/面板），新画框默认取当前类别，
  `AnnotationCanvas` 新增 `defaultCategory` prop，删掉写死的「前缘侵蚀」。
- 提交带真实 `expected_version`（来自 `review_version`），三态明确：
  `no_defect`（框必须为空）/ `confirmed`（必须有框）/ `rejected`（驳回不计入确认样本）。
- 409 版本冲突：提示"记录已被他人更新"并重新拉取，**不覆盖别人的提交**。
- 服务端成功后才刷新队列；结果提示不会被刷新动作清掉（这是第一版测出来的 bug：提交成功了但提示瞬间消失）。

## 4. 设置页个人连接（13.4 之一）
