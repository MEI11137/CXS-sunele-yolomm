# INT-37：数据集页面收敛为两条主线

日期：2026-10-29；实施工具：Codex；目录：海巡智检v1.1。

## 用户确认的方向

保留业务服务及手动/Agent双入口，将“数据集、反馈池、候选草稿”三个平行页面改成“我的数据集”和“从复核生成新版本”两条主线。

## 页面变化

- 我的数据集：合并名称、模态和时间信息，主要操作为进入模型管理、重新划分；整理当前来源反馈和删除收进“更多”，回收站保留。
- 反馈主线：1收集已确认样本 → 2选择来源 → 3整理并生成，允许直接继续已有待完成版本，不要求反复切页。
- 第一步分别显示已确认未入池、已入池、待复核；明确仅当前载入最近50条的数量，不冒充全项目统计。复用feedbackEligibleRecords，不重复提交已入池/未确认项，一次确认并显示部分失败原因。
- 第二步明确选检测模型实际关联的原数据集；优先选当前已知入池记录的来源，说明正式样本数量不等于反馈池数量，提取成功自动进入整理。
- 第三步将旧草稿作为“待整理版本”管理，嵌入原样本划分编辑器；生成成功后返回正式数据集列表。不会自动合并原训练集、训练、发布或减少原数据。
- DraftEditor文案改为设置样本用途、检查并生成数据集、返回待整理列表；调用的原assign/finalize服务不变。
- 保留旧tab=images/feedback/drafts与draft查询参数，Agent原有打开指定草稿功能仍能直接进入第三步；未改变工具名、鉴权或业务数据结构。
