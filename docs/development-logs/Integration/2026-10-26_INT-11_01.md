## PDF、Word 与资料问答入口

1. PDF 使用固定依赖 `pypdf==6.6.0`，按真实页树读取页面，不再按 PDF 对象编号排序。
2. DOCX 继续复用 OOXML 段落/表格解析。扫描 PDF 缺文本、加密/损坏文档会返回 partial/failed 或明确提示；不伪造 OCR。
3. 受保护文档列表、解析、检索 API 和 `DocumentLibrary.vue` 已接通；解析按上传文件 ID 和本人项目校验。
4. 检索片段带文档 ID、原文件 ID、内容版本以及页/段落/表格定位。原文通过文件权限接口读取，可打开受保护原文件；PDF 支持页码链接。
5. 补齐文件上传/元数据返回的 bucket/object_key，使原文件读取与前端文件契约一致。
6. 修正同内容文档重复解析返回 id/document_id 不一致的问题。
7. Agent 通过现有 document.parse/search 业务工具取得内容；文档不是系统指令，不能扩大工具权限。
