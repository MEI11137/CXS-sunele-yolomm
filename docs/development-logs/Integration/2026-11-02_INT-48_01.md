# INT-48：v1.3.1 修正、付费 API 核验与评委反查

日期：2026-11-02。操作：Codex；用户授权继续修复、使用本人付费 API，并把真实训练留在另一台服务器。

## 改动

修正 INT-47 六项缺陷，复用原业务服务与个人连接；将此前独立对话修正中的前端独立轮询和有界只读请求合入。补齐训练启动前占用、项目登记、PID 交接门控、子进程树取消、失败回滚、工作区安全导出和增强图失败清理。

评委反向走查额外修正：业务 watcher 线程读写错误数据库风险；已删除模型导致等待不结束；用户拒绝命令后不收尾；增量训练页面漏查反馈数据集权限；子模型未登记；未校验数据集/类别顺序不一致仍提交；前端父子对比格式不符、缺失指标被当作零。增加页面取消训练入口，与 Agent 共用同一取消服务。

VERSION、package/锁文件、启动提示和当前说明统一 1.3.1。历史版本日志与开源来源保留。
