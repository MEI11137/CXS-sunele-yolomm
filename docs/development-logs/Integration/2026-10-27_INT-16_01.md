# INT-16：项目会话历史与演示前清理

- 日期：2026-10-27
- 实施工具：Codex
- 分支：feature/opencode-agent；保留三人现有改动，未推送、未合并、未改动已发布版本标签。

## 用户需求

按参考截图，将左侧列表改为工作区下展示各自会话历史，清楚标识新会话所属项目，支持点击查找历史对话。另按用户明确要求清理之前的数据集、模型与会话记录，准备重新演示完整闭环。

## 功能与实现

1. 新增 ProjectConversations.vue，负责项目分组、展开/折叠、会话标题搜索、每个项目的新建按钮和历史加载错误提示。桌面侧栏与移动导航共用；点击会话会打开助手面板。
2. 会话缓存由单项目数组替换改为按 project_id 分组的共享列表；活动项目与每项目选中会话分别保存。刷新历史保留已有对象，避免丢失正在接收的回复；迟到的新建会话不会抢占其他活动项目；重复点击新建只提交一次。
3. 工作区与当前会话的联动由 AppLayout 中的同步工作区监听协调，避免助手组件清空全列表。历史会话选择主动加载消息，右侧显示工作区名称与会话标题；右侧简易历史菜单仅列出当前工作区。
4. 首条用户消息生成最多 60 字的标题，并通过 agent/sessions.py 持久化；自定义标题保留。输入草稿和附件按账号/项目/会话保存，账号切换时清理，避免跨会话混用。
5. 每项目最多加载最近 200 条会话，达到上限时明确显示提示。当前搜索按已加载会话标题及工作区名称匹配，不是全文消息检索。
6. utils/db.py 仅在首次创建 datasets 表时种入内置演示资源；已有数据库中的演示资源删除后，服务重启不会再次插入。

## 清理范围与结果

最初只读盘点发现，数据集和模型仅剩内置演示资源，而不是实际上传的私有资源；用户要求从空状态录制闭环，因此一并清理它们及其关联测试记录。操作通过精确 ID 和所有者校验，在停机后备份，再使用 SQLite 事务处理；不是遍历磁盘删除文件。
