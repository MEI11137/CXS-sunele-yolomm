# INT-19：网页与嵌入式 OpenCode 共用模型连接

- 日期：2026-10-27；实施工具：Codex。
- 需求：网页 Agent 与网站后端 OpenCode 使用同一 API 连接。
- 核对现有实现：设置保存至当前账号的加密连接；OpenCodeRuntime 每轮读取该连接，EnginePool 检测 Key、地址或模型变化后重建引擎；原 AI 核查也读取该连接。复用此链路，没有新增第二套配置或同步服务。
- 界面：设置中的「大模型连接」明确说明共用范围与下一次对话生效；保存提示同步更新。
- 修复：测试连接时总是先保存当前表单，解决只改 Base URL 或模型、Key 留空时仍测试旧配置的问题。
- 回归：使用真实本机 OpenCode 1.19.4 与模拟模型服务，验证请求的认证、地址和模型同步更换；旧进程关闭、旧桥接令牌撤销；删除连接后新消息失败且不回退其他 Key。未使用用户真实 Key，未调用付费服务，未修改业务数据。
- 验证：后端定向测试 6 passed；前端 vue-tsc 与 Vite 构建通过（129 modules）。
- 边界：独立 4096 客户端不自动导入或覆盖；在途请求不中途换 API。能力检查仍以实际模型支持为准。
