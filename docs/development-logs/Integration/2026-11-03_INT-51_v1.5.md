# INT-51：真实评委日志驱动的 v1.5 修复

日期：2026-11-03。来源：协作仓库 logs-20261103 日志分支；源码基线为 release/haixun-v1.4.0。完整原始日志与网页截图仅保留本地，不在此复制账号、路径、内部 ID 或凭据。

## 原因与改动

1. ChatPermissionPicker、sessions.set_permission_mode、deploy.gateway 三层都限制普通账号。取消角色门禁，继续检查本人会话、演示入口登录与绑定目录；普通账号不能据此操作其他账号项目。
2. AgentProgress 的执行详情默认 open；引擎多轮工具间的文字均作为普通消息展示。改为默认折叠，并为普通执行说明保存 execution_note 标记；不保存 reasoning 类型。最终回答依然独立更新，避免重新发送“你好”才能取得结果。
3. HxEngineRuntime 继承旧执行器的多写入计划门禁；本地文件登记又未被列为常规业务。移除 OpenCode 路径的计划门禁和工具暴露，旧 propose_plan 调用无副作用返回；登记工具复用现有会话策略。
4. FileRegisterLocal 将 kind=image 固定落为 project_file。纠正新登记，旧登记在受保护网关内验证图片后兼容；验证临时文件使用后清理，不放宽为任意文件检测。
5. InspectionLoopTools.prepare 枚举模型索引时直接读取对应业务行，残留索引会抛 FileNotFoundError。跳过无业务行的候选；bridge 与 MCP 返回结构化失败，超时及不确定结果明确标为 unknown，禁止自动重做。
6. 实测后台任务提交后 Agent 尝试用 Start-Sleep 等待，导致多余权限拒绝说明。补充后台接管的明确工具结果与提示，精简兜底通知；后台检测和 AI 核查不依赖对话轮询存活。

- tests/test_agent_backend.py：更新已改变的角色要求，保留未登录、非法模式、跨账号拒绝。
- deploy/tests/test_gateway.py：已授权评委请求可以到达权限接口，未登录拒绝；私有桥接及连接管理仍禁止公开。

- 本机普通角色实际页面与内嵌 Agent：切换 assist，回答一次候选数据源，随后完成 3 张真实检测、3 次个人 API 多模态核查，并自动跳转带 flow_id 的人工复核队列。人工标注未自动提交，未运行训练。
