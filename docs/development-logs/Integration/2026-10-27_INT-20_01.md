# INT-20：海巡助手对话交互改造

- 日期：2026-10-27；实施工具：Codex；分支：feature/opencode-agent。
- 起因：助手回复误用 `.assistant` 类，被套用侧栏容器的宽度、高度、背景和 flex 样式，形成窄长色块；原有消息监听和发送回调无条件置底，上翻历史后仍会抢走位置。

## 改动

- `AssistantPanel.vue` 保留原消息、附件、停止和项目权限链路，统一桌面与手机抽屉的组件结构；主对话统一使用面板背景，输入框和用户消息保留轻量层次。
- `ChatTimeline.vue` 独立管理消息布局与滚动。消息使用 `chat-*` 类，解除侧栏样式污染。消息列与输入框居中对齐，滚动条回到完整视口右缘。
- 位于底部时跟随真实更新；向上阅读即解除跟随，新增消息和工具卡片不会抢走位置。显示向下箭头及新消息提示，点击后回到最新并恢复跟随。会话切换与主动发送可进入最新位置。
- 底部判断仅保留 2px 浮点容差，避免短会话刚上翻就被宽松阈值重新吸回。ResizeObserver 同时处理回复、工具卡片和窗口变化。
- 输入框随文本自动增高；附件入口、上传状态、移除/重试与停止操作保留。增加回复复制，支持减少动画的系统偏好。业务页面右侧新建会话不强制离开业务页。
- `AgentProgress.vue` 将进度放在最近提问之后；同一次调用的 running/completed 等事件合并成一条，默认展示步骤摘要，输入和原始结果可展开。计划、写入确认和人工入口始终可见。后端补充真实 tool_part_id/call_id，供前端准确归并。
- `ChatModelPicker.vue` 位于输入框下方，打开时读取当前服务商模型目录，支持搜索、刷新及手填模型 ID。切换通过原个人连接保存接口完成，保留服务地址与服务端 Key，下一次请求使用新模型。整个账号的聊天、后端引擎与 AI 核查继续共用该配置；切换后能力需要重新验证。
- 新增有鉴权的 `GET /api/agent/connection/models`。仅访问本人当前连接，8 秒超时、不自动重试；目录失败时保留当前模型并给出说明，不编造模型列表。目录查询不会发起聊天生成。异常信息补充本人 Key 脱敏。
- 调整模型菜单位置，避免右侧栏的弹出内容超出屏幕。保留现有深色和浅色主题与原网站业务入口。

## 验证

- 前端：类型检查及 Vite 构建；会话状态和工具生命周期测试共 14 项通过。
- 后端：Agent 基础及新模型目录接口 23 项通过；OpenCode 配置/真实协议测试 20 项通过（真实本机引擎配合模拟模型服务）。首次新增目录异常测试发现 Key 回显，修复后重新通过目录测试及完整 Agent 基础组。
- 浏览器隔离验收：上翻到历史后追加模拟回复，scrollTop 保持 0；点击回到最新后距离底部为 0，再追加仍为 0；模型菜单选择后显示新的模型 ID；右侧菜单右缘不超出视口；336px 侧栏与 366px 抽屉无横向溢出。
- 实际网站：复核短会话上翻后保持在顶部并显示箭头，助手消息宽度恢复 802px；保存深色实页截图。未发送真实模型请求、未修改用户模型连接或业务数据。
- 后端更新前检查无执行中/等待执行任务和训练锁，仅重启已核对的网站进程。健康接口 200，新模型目录匿名访问 401。
- 隔离 UI 验收入口为开发服务器 `/tests/chat-ui.html`；仅挂载内存模拟数据，不接真实业务接口，不进入生产单入口构建。
