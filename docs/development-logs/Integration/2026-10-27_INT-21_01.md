# INT-21：海巡助手会话权限与批量批准

- 日期：2026-10-27；实施工具：Codex；开发分支：feature/opencode-agent。
- 用户确认：三档均保留删除确认；明确只读和常规操作可自动，无法判断影响的命令仍需人工确认。复用现有 OpenCode 权限请求及站点动作记录，不另造 Agent 执行循环。

## 实现

1. **产品命名**：原生权限卡按操作类型显示海巡助手读取与查询、文件修改、删除或命令操作。历史卡的标题、摘要及预览 tool_title 在界面兼容替换；原始审计记录和第三方许可证保留。卡片使用项目名称，批准按钮说明本次操作。
2. **会话权限**：SQLite 加法迁移至 schema 6，agent_session 新增 permission_mode，旧会话默认 request。新增有鉴权、仅本人会话且仅管理员可设置的 `PUT /api/agent/sessions/<id>/permission-mode`；模式不由工具参数或模型输出决定。
3. **三档区别**：request 自动读取，修改请求确认；assist 再自动批准项目内明确文件修改；full 再自动批准通过预检的 New-Item、Copy-Item、Set-Content、Add-Content 等常规命令。删除、清空、移动、项目外及未知影响的请求均不自动放行，现有业务确认不被此模式取消。
4. **程序预检**：原生 read/glob/grep 保留自动读取。Windows 命令通过受信系统 PowerShell 的 AST 解析器检查；只解析输入，从不执行待检查命令。采用静态语法、命令/参数允许清单与规范化项目路径检查；嵌套删除、脚本执行、重定向、方法调用、赋值等不能按只读自动放行。解析失败、超时或系统不支持均回退人工确认。
5. **自动批准的记录**：复用原有动作状态与真实结果回写，并记录 permission.auto_approved 事件。仅回复原引擎 once；删除仍待人工批准，不创建长期通配授权。模式改变后可接续符合规则的待批准文件修改，保留审计事件和结果核实。
6. **批量删除**：提示引擎先收集并说明完整目标，将同批路径合并在一条 Remove-Item 命令或可用的单份补丁中，申请一张卡。批准只覆盖该命令/补丁，参数或目标变化后需重新确认。不是授予会话永久删除权。
7. **界面**：输入框下方新增权限选择；升级先展示实际能力并要求点击启用。模式按会话保存，切换会话不会串用。待批准与真正执行中分开显示，待批准时可以调整模式；原先发出的慢历史请求不能覆盖刚保存的新模式。
8. **文件处理边界**：嵌入式引擎固定使用受信 PowerShell（Windows），关闭自动 formatter/LSP 后处理，避免自动写入文件时隐式运行项目格式化脚本。原生 Shell、未知程序仍可由管理员核对后批准；工作目录和规则检查不是 OS 沙箱。

## 使用

刷新项目对话页，在输入框下方选择权限模式。希望普通项目文件修改不反复确认时启用「帮我批准」；需要自动执行明确常规文件命令时启用「完全访问」。两档均保留删除和未知命令确认。普通账号不能开启本机文件权限模式，业务权限与人工复核规则继续生效。
