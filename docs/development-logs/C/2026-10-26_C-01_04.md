# C-01 第 4 轮：幂等回放与旧资源授权

- 时间：2026-10-26；执行：Codex。
- 问题：同一 `request_key`、同一工具输入在资源版本变化后被误判为不同参数；旧操作查询只检查资源当前归属，未复核执行时的项目授权。
- 修改：幂等比较改为工具名称及规范化输入；回放与操作查询同时检查当前资源和操作记录中的原资源快照。不同输入仍拒绝。
- 接口影响：同键同输入跨版本返回原结果，不会发起第二次业务执行；旧项目授权撤销后不能读取原操作结果。
- 验证：新增两个回归测试，C-01 工具测试 20 项通过。未接入第二人的正式权限服务，项目与版本仍依赖可信注入回调。源码副本无 Git 元数据，暂无提交或 PR。
