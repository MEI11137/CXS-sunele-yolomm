- 本次目标和原问题：
  - 原 `/api/dataset/upload` 把校验、存文件、写库混在路由里，Agent 无法复用；校验遇第一个问题即抛错，用户一次只能修一处。
  - 文件上传（C-02）只有 `uploaded` 状态，没有“这份上传已经变成数据集”的绑定，重试有登记两份数据的风险。
  - 工具层参数校验是“每个工具一个字段”的硬编码，无法承载多参数工具。
- 给 AI 的材料与关键词：任务书 C-03（YOLO 数据集校验、类别映射、归一化坐标、RGB/X 配对、权重导入关联、先预览后登记）；总体方案文件与权限要求；现有 `dataset_contract`、`model_import_service`、`routes/dataset.py`、C-01/C-02 接口说明
- 修改文件、具体业务及修改前后差异：
  - 新增 `services/dataset_import_service.py`：`inspect_dataset_archive` 一次收集全部结构/配对/标签问题（20 余个稳定 code，区分 blocking 与 warning，最多列 200 条并给出真实总数），输出类别、模态、各 split 样本数、拟登记字段；`import_dataset_archive` 重跑 `validate_dataset_archive` 作为唯一权威、生成缺失的 `data.yaml`、存归档、在单事务内写 `datasets` 并执行可选的 `on_registered(conn, dataset_id)` 绑定钩子，失败回收已存对象。
  - `routes/dataset.py`：`/upload` 改为调用共享服务，入参与错误文案保持原样，响应新增 `class_names`、`split_counts`、`samples`、`warnings`（原字段不变）。
  - `services/business_tools.py`：参数校验改为按工具 `input_schema` 的严格子集校验（类型/枚举/长度/条数/禁用多余字段）；工具注册表增加 `_ToolSpec`，声明资源类型、ID 字段与所需动作，新增项目资源范围；新增 `dataset.import`（预览含预检报告、来源文件快照、拟登记项、`blocked_reasons`、`ignored_arguments`；执行时复核 sha256 与项目权限，已绑定的上传返回 `reused: true`，预检阻断时以 `failed` + `item_results` 结束）；构造参数新增 `file_assets` 与 `storage_client`，缺失时该工具不开放。
  - `services/file_access.py`：`file_assets` 幂等补 `business_type`/`business_id`/`updated_at`；新增 `require_import_asset`、`link_business`、事务内版本 `link_business_with`，一个上传只允许绑定一个业务资源；`registered` 与 `uploaded` 同样可读，已绑定上传不再允许经 HTTP 删除入口移除；新增 `LocalFileAssetGateway`（resolve / materialize / bind_with）供工具层注入。
  - `tests/test_dataset_routes.py`：两个用例原来用只记录 SQL 的假库，改为临时 SQLite 后断言真实落库结果（更强，且适配共享服务的 `get_connection()` 约定）。
  - 新增 `tests/test_dataset_import_service.py`（18 项）、`tests/test_business_dataset_import_tool.py`（11 项）、`docs/dataset-import-c03.md`。
- 优化原因：让页面与 Agent 共用同一套“可导入”判定；把“上传成功”与“已登记为数据集”分开；在真正写库前把全部问题摆给用户；杜绝同一份压缩包被登记两次。
- 对第一人/第二人的接口、迁移和旧页面影响：
  - 第二人：`resolve_resource` 需支持 `kind="project"` 并返回带 `project_id`/`owner_id`/`version` 的快照；需提供 `file:read` 与 `dataset:create` 两个动作的裁决。构造适配器时注入 `file_assets=LocalFileAssetGateway(db_path, file_client, project_access, work_dir)` 与 `storage_client=file_client`。未注入时 `dataset.import` 不出现，`prepare_tool` 直接抛 `ValueError`。
  - 第一人：旧上传接口字段全部保留，仅新增三个只读字段；上传后的文件状态会出现新值 `registered`，预览/下载不受影响。
  - 迁移：`file_assets` 启动时自动补三列，无需手工改库；`datasets` 表结构未变。
- 数据/文件保护方式和输出位置：测试只用 `tmp_path` 下的临时 SQLite 与临时文件存储；未触碰运行中的数据、模型、数据集与上传目录；`project_uploads` 原件保留，登记后的归档另存于 `datasets` 桶。文档只描述结构与错误码，不含私有样本内容。
