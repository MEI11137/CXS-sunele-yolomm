# 海巡智检 v1.3.1：修正与评委视角验收

日期：2026-11-02。基于共享仓库 `MEI11137/CXS-sunele-yolomm` 的 `release/haixun-v1.3.0`，上游提交 `32d1d34ea246ac0b4e039c15bfc9abb28eb85f82`。本轮在独立副本修正，未覆盖原 v1.3、队友分支或服务器运行数据，未推送 GitHub。

## 1 本轮修正

| 问题 | 最终行为与主要代码 |
| --- | --- |
| 工具成功后最终答复丢失 | `agent/hx_engine_runtime.py` 只按最新 assistant 消息的结束状态收尾，工具调用结束不等于最终答复结束；用户拒绝操作时也能收尾并说明。 |
| 页面轮询被任务接口阻塞 | `AgentProgress.vue` 将消息读取和任务/事件读取分开；相关只读后台请求设定超时，切换项目/会话清理轮询。不自动重试写操作。 |
| 取消训练假成功 | `training_runner.cancel_training_job` 记录 PID 及创建时间，核实整个子进程树退出后才标取消并释放训练槽。拒绝访问、仍存活或进程身份不明时保留占用，返回具体失败。页面新增取消入口，与 Agent 共用实现。 |
| 训练创建和进程移交异常 | 先预留训练槽，再创建记录、登记真实项目归属；失败标失败。页面和 Agent 共用带启动门控的 worker，PID 移交前不开始训练；未能确认清理的进程不释放占用。 |
| 数据集导出路径越界 | `dataset.export_zip` 使用受控 ID 与随机文件名，写入项目 `exports/datasets`，核验实际目录，不使用用户可编辑的名称拼路径，不覆盖旧导出。修正工具写入声明。 |
| 图片增强登记失败 | 复用有项目权限回调的附件网关，支持中文路径，登记到实际项目；失败清理本次上传和临时副本，原图不变。 |
| 分析/建议误用全局连接、遗漏红外 | 两工具复用共享 AI 核查服务和当前用户个人客户端。需要看图时同时传入实际 RGB/配套图；无全局模型回退；明确标注付费和写入，建议最多两次模型调用。 |
| 训练完成不主动通知 | `business_watcher` 在所属 Flask app 上下文内查询业务状态并写回同一会话；模型已不存在时明确失败，不永久等待。 |
| 增量训练权限/归属遗漏 | 页面独立检查反馈数据集读取权限，并核验显式项目；训练子模型在启动前登记到真实所有者/项目。未校验数据集、已知类别表/顺序不一致时拒绝训练。 |
| 父子对比无指标、缺失值显示零 | 前端按后端 `metrics[指标].parent/child/delta` 读取；支持 `mAP50-95`，未知显示 `—`。说明验证条件不同不能直接断言效果提升。 |
| 版本标签不一致 | VERSION、前端 package/锁文件、启动提示、README 和迁移说明统一为 1.3.1。保留上游来源与开源声明。 |

人工上传、原页面检测、数据集划分、模型导入、复核、反馈、发布入口均保留。Agent 最终人工确认边界未移除。

| 评委动作 | Agent 能否操作 | 本轮证据与边界 |
| --- | --- | --- |
| 进入演示、登录、访问自己的项目 | 项目/会话工具已有 | 部署测试包含真实本机 HTTP、普通演示账号隔离与 SSE；未从外地访问你的当前服务器。 |
| 建项目、绑定目录、查看项目文件 | 有项目及文件工具；权限按身份 | 服务器 Agent 读的是服务器目录。另一台客户端的未上传文件仍必须经文件选择器/拖拽上传。 |

| 单条/批量 AI 核查 | 有单条/批量及整轮工具 | 个人连接真实小请求和实际分析/建议已调用；批量预授权、防重及真实配套图参数另有回归。没有对整份私有数据集付费扫描。 |

| 回原数据集或另建数据集、划分与定稿 | 有反馈、修订、草稿/划分/定稿工具 | 既有来源匹配、去重、原样本标注替换、工作区输出相关用例纳入回归。未替你修改真实原始数据。 |
| 开始训练、失败恢复、取消 | 有初始/增量/状态/取消工具 | 本轮验证占用、错误、归属和真实无害进程树取消；没有启动真实 GPU 训练。 |

## 3 仍有的功能缺口与验收工作

1. **必须在服务器做真实训练验收。** 初始/增量训练各用小数据跑 1 轮，核对 CUDA、显存、DataLoader、日志、best.pt、指标、取消进程、发布与复测。训练取消要在真实 DataLoader 工作中再验证。本轮没有进行真实训练。
2. **模型列表只请求前 50 项，详情逐项串行读取。** 少量模型可用，模型较多时可能慢或漏出第 51 项后的可选模型。后续应使用分页或后端一次返回完整 DTO；本轮不改变该接口。
3. **初始训练的手动页面不完整。** 当前模型管理主要提供“已有父模型的增量训练”和权重导入；初始训练可由 Agent 的 `business_model_create` 发起，不能将它当作已有完整手动表单。单模态初始训练还需要服务器准备可用基础权重。
4. **部分界面控制没有完整 Agent 参数。** 例如人工复核配套红外图的独立缩放目标。业务已能执行不等于任意复选框、弹窗和视图都可控制。
5. **连接配置、密钥输入及授权仍有人工入口。** 保存 Key、外部 MCP 放行、额外目录授权、权限模式不能由模型自行批准。当前模型下拉有页面接口，但没有独立的 Agent 模型切换工具。这与业务动作接口缺失要区分。
6. **本机管理员保留旧站维护权限。** `agent/resources.access_check` 仍有管理员维护全库的兼容分支；普通账号不能据此越权，公网网关禁止管理员登录。现阶段不宣称严格的多租户最小权限 SaaS；若后续开放多人管理，需要统一这一历史策略。
7. **后台完成通知按单个站点进程部署。** 本轮修正了 app/数据库上下文和已删除模型的悬挂。多进程 WSGI、跨进程通知去重不是本轮已验收能力。
8. **真实客户端还需逐页走通。** 本轮前端测试与构建通过，不代替服务器浏览器对上传、缩放、滚动、移动设备、刷新/断网续接的完整验收。尤其要核对服务器是否已更新新的前端 dist 与后端进程。

结论：具备可演示的项目内 Agent 业务闭环，但“训练迭代全链路已经真实跑通”和“所有页面动作都已能由 Agent 操作”目前都不能作为验收结论。

## 4 服务器更新

建议使用同批 `海巡智检v1.3.1_增量更新_20261102.zip`：只包含本轮源码改动、文档和重建的前端 dist，不带数据库、密钥、模型、数据集、依赖或引擎二进制。

1. 在服务器确认当前源码版本，停止当前站点与网关，先等训练结束；不要中断真实 GPU 训练来更新。
2. 解压更新包，先运行 `应用更新.ps1 -ProjectRoot '实际源码根目录'` 做只读检查。它会检查旧文件内容，遇到队友修改或非本次基线立即停止。
3. 检查通过后加 `-Apply` 执行。它先备份将替换的代码文件，再覆盖，不改 `.demo-state`、数据库、Key 和项目数据。
4. 使用服务器原有 Python/CUDA/引擎及原配置重新启动。前端 dist 已提供，无需因本轮修正重装 Torch/CUDA。新锁字段由现有迁移逻辑按需补充。
5. 刷新浏览器；检查版本和以下脚本。更新不代表当前运行的旧进程会自动加载新代码。

完整源码包用于干净部署；如果换目录运行，先按服务器已有环境配置重设路径，不把旧版运行数据复制成公开参赛源码。

## 5 服务器最后验收脚本

- 问“读取当前数据集结构”，不再发送“你好”补救，等待最终文字自行出现；刷新后仍能找到同一会话回答。
- 工具或命令被拒绝后，界面停止等待，说明哪项未执行；拒绝前已完成的操作不能被笼统说成“文件没变”。
- 选一条记录执行真实 AI 核查，核对 RGB/IR 和本人连接，再试勾选两条批量核查，确认范围不扩大。
- 人工修正一张旧图和一张新图；回原修订版预览应分别计入修正/新增，文件在项目下，原版可追溯。
- 增量训练 1 轮，另一个会话同时申请训练应提示忙；完成后聊天自动通知，模型归当前项目，出现真实权重和指标。
- 对可中断的小训练执行取消，确认后台进程及 DataLoader 子进程均退出，再启动下一项。
- 对比父子模型：有值显示真实数值、缺失显示 `—`；验证集不同不以差值宣称效果提升。
- 用普通账号尝试引用另一账号的私有数据集，应拒绝并且不产生子模型、训练或额外 API 消耗。
- 发布新模型后检测 1 张图片，确认记录包含实际模型、数据来源与版本；这才完成包含真实训练的最终闭环。
