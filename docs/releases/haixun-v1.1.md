# 海巡智检 v1.1.0 源码交付

本版在`feature/opencode-agent`分支提交协作审查，不覆盖main，不改写队友分支或既有v1.0标签。

## 主要行为

- 项目绑定本机文件夹，会话和业务页面跟随项目；默认显示对话，人工复核等页面保留助手侧栏。
- 内部OpenCode调用网站业务工具进行图片检测、单条/批量AI核查、人工复核衔接、反馈入池和数据集版本生成。
- 复核标注保留人工确认；配套RGB/红外均可缩放平移。回原数据集生成修订版时，同源图片替换对应标签，新图片才追加。
- 数据集来源/重复检查、划分、模型导入、增量训练/比较/发布复用实际服务。
- 项目/会话管理、历史读取、CSV导出、PDF/Word资料、手册与固定界面命令均有Agent入口。
- 常规业务按会话批准模式执行；删除、已有文件修改及未知命令等保留相应确认，不由模型自行提升权限。

完整能力与限制见[覆盖清单](../integration/Agent功能覆盖复核_2026-10-29.md)。图片检测及数据回流的验收不等于已完成所有训练效果或视频/实时Agent验收。

## 获取与启动

仓库根目录现在包含`start.ps1`、启动/检查/停止cmd；深层旧入口指向同一份仓库内脚本，不再依赖仓库外文件。安装Python、前端与OpenCode依赖并配置本机路径，按[README](../../README.md)启动。启动器不会下载依赖或复制个人凭据。

## 干净数据与协作

源码交付排除数据库、Key、权重、运行日志、上传素材和依赖。新安装只初始化账号/表结构等基础状态，不预置虚构模型或数据集。各人单独创建项目、导入素材并配置API；本机测试清理备份留在仓库外。

版本号为1.1.0；本次推送源码分支，不自动发布Release或合并main。开发日志INT-14至INT-43随源码保留；第三方授权声明继续保留。
