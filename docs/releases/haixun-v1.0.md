## 版本内容

1. 同一项目中的新 Vue 前端、Agent 公共服务与真实业务后端。
2. 个人模型连接、工作区、全局对话、真实工具事件、计划与动作确认、停止和人工处理接力。
3. 图片巡检、AI 辅助核查、人工标注确认、反馈草稿、划分定稿、增量训练与发布入口。
4. stdio/Streamable HTTP MCP、版本绑定的逐工具授权、本人项目目录授权。
5. PDF/DOCX 阅读、检索及原文定位，任务手册版本快照。
6. 真实反馈图片/标签合并、源数据变化阻断、训练进程状态与资源归属修复。

- 现用 Python 环境：423 项通过、2 项因 Windows 符号链接限制而跳过，另有 5 个子测试通过。
- 新前端：类型检查和生产构建通过。
- 浏览器：文档上传/解析/检索/原文读取、MCP 配置/发现/授权、目录授权、九个页面导航和复核检查通过。

使用原有可运行 YOLO 的 Python 环境，安装后端 `requirements-agent.txt`。前端目录是 `CXSDet-YOLOmm/CXSDet/web-haixun`；完整启动步骤见 [交接说明](../integration/接续说明_2026-10-26.md)。

源码版本不包含本机数据库、API Key、上传文件、数据集、PT 权重、node_modules 或测试账号状态。运行所需的个人模型连接、数据集与权重由各人自行配置。
