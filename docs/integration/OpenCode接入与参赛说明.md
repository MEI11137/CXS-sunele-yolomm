# 海巡智检 OpenCode 接入与参赛说明

日期：2026-10-27。开发分支：`feature/opencode-agent`。此次实现：Codex，延续此前 WorkBuddy 与三人协作代码；不将本次操作记为 WorkBuddy 执行。

## 运行方式

站点默认执行器改为 OpenCode 1.19.4。保留现有 Vue 聊天窗口、Flask 会话接口、人工确认卡和真实业务服务。本次没有把 OpenCode 原生网页嵌入网站；`127.0.0.1:4096` 仍是独立体验入口。

链路：网站消息 → Flask 身份/项目上下文 → 独立 OpenCode HTTP 进程 → stdio MCP → 本机私有业务桥 → 原有工具权限、预检、确认与执行。回复按 OpenCode 消息 ID 写入网站历史，由现有任务轮询展示。

默认从 `E:/OpenCode/bin/opencode.exe` 查找程序，或通过 `OPENCODE_BIN` 指定。服务启动后才按需创建引擎；每个用户的每个会话独立进程、模型连接、状态与工作目录，默认最多 4 个活跃实例。引擎只监听回环地址并使用随机服务密码，不与独立体验版共享模型凭据。

业务桥默认地址 `http://127.0.0.1:5020`。如果 Flask 改端口，需设置 `OPENCODE_BRIDGE_ORIGIN` 为实际本机根地址，且启用多线程请求处理。状态目录默认位于 Flask 的 TEMP_DIR/opencode；可通过 `OPENCODE_STATE_DIR` 放在指定 E 盘目录。运行目录不可提交 Git。

## 模型与工具边界

### 统一 API 连接

入口为「设置 → 大模型连接」。当前账号只维护一份加密连接：网页对话由后端将同一 API Key、Base URL、模型名注入嵌入式 OpenCode；原页面 AI 核查也读取这份连接。无需另行修改 OpenCode 配置文件。

保存后，下一次发送消息会读取新配置；如配置变化，旧会话引擎关闭、私有工具令牌作废并以新配置重建。正在进行的请求不承诺中途更换 API。删除连接后，新消息明确报未配置，不回退到其他账号或独立客户端的 Key。

「测试连接」先保存当前表单，包括仅修改地址或模型且 Key 留空的情况，再检测这份配置。留空 Key 表示沿用已保存的 Key。能力检测会向所配置服务发出真实请求；文本模型不因共享配置而自动获得图片理解能力。

此处的“共用”指本站网页与本站后端的 OpenCode 引擎；另行打开的 `127.0.0.1:4096` 独立客户端仍有独立配置，不自动导入或覆盖它的凭据。

- 使用每个用户在网站设置中保存的当前模型连接；API Key 只在服务器解密，注入对应引擎进程，不写入源码或明文配置文件，不继承个人 OpenCode 的免费模型。
- 网站 AI 核查仍走本人视觉能力检查；更换调度引擎不会让纯文本模型自动具备看图能力。
- 普通用户保留自己的业务工具权限，禁用原生 Shell 和原生文件写入。
- 本机管理员可在输入框下方为当前会话选择「请求批准」「帮我批准」「完全访问」。项目内原生读取直接可用，明确的只读 PowerShell 经过程序预检自动批准；帮我批准允许明确文件修改，完全访问再允许预检通过的常规文件命令。三档都保留删除、清空、移动和未知命令的人工确认。自动范围限定项目文件夹，业务确认独立保留。
- 文件/命令卡片统一使用「海巡助手」，显示实际工作目录、完整参数与影响。一次批准覆盖本条命令或整份批量补丁；目标变化后重新确认。无论自动还是人工批准均只向原引擎回复 `once`，不创建通配永久放行；执行结果仍须由实际工具返回。
- 原生文件操作默认限于独立会话工作目录，外部目录访问默认拒绝。需要处理既有数据集时，继续使用本站授权目录和业务文件工具。本次没有开放任意 E 盘目录给原生命令。
- 命令使用本机操作系统账号权限，工作目录和应用确认并非操作系统沙箱。本版面向各人本机使用；多人共享服务器部署须另行完成 OS 级隔离。
- 检测、核查、反馈、定稿、训练与发布继续复用原有业务权限和确认；工具没有返回真实结果时不标为成功。普通问答不再被旧待确认动作直接挡住。
- 刷新页面不会重发已执行工具；停止会向 OpenCode 发送 abort。后端重启不自动重做付费核查或训练；旧原生权限请求失效。会话历史仍在网站库中，续接按真实业务状态进行。

## 运维与回滚

正常启动步骤不变：安装现有 `requirements-agent.txt`，运行 Flask 与 Vue 前端；同时需已安装匹配版本的 OpenCode。无需 JS/TS SDK，也无需在 Flask 里增加 Node 后端。

必要时设置 `AGENT_ENGINE=legacy` 后重启 Flask，可显式回滚旧执行器。没有自动降级：OpenCode 缺失、版本不匹配或启动失败时会明确报错。回滚不会覆盖或删除会话、业务数据。

## 为什么开源软件有默认模型

开源许可证覆盖软件代码；模型托管服务是另一层。官方将 Big Pickle 列为限时免费云端模型，并说明免费期数据可能用于改进模型。它不是下载包里的本地权重，也不意味着你获得了该模型的所有权或无限调用、转售权限。

正式演示使用个人获授权的模型连接，并遵守对应服务条款。官方模型、额度和政策可能调整，不能依赖免费服务永远可用。
