# 网站与内嵌Agent功能覆盖复核

日期：2026-10-29。实施：Codex。范围：海巡智检v1.1当前web-haixun页面、Flask业务处理器和网站OpenCode实际注册目录。

INT-41更新：**本次已将项目/会话管理、CSV、资料列表与原文、任务手册及明确列出的界面命令接入网站内部Agent。**“有HTTP路由”“有模型可调用工具”“完成真实环境验收”是三个不同层次，不能相互替代；不宣称任意按钮和设置都可交给模型。

## 1. 已有对应Agent工具的主要业务

| 功能 | 实际工具/入口 | 说明 |
|---|---|---|
| 当前项目资源查询与业务页面导航 | workspace_query_resources/list_resources/open_page | 查询真实ID、版本与项目归属；不是通用浏览器点击器 |
| 查工作区数据集/权重并登记本地附件 | workspace_discover_inputs/attach_file | 校验绑定路径与权限，原始素材保留 |
| ZIP数据集与PT模型导入 | business_dataset_import/model_import_weight | 共用导入服务，校验格式、类别和模态 |
| 单图检测、批量巡检与单条/批量AI核查 | business_detection_run/review_ai、workspace_start_inspection_loop | assist/full常规业务自动执行；批次对象及数量仍需明确，失败不自动重复付费 |
| 复核页面定位、缩放、平移和标注草稿 | workspace_review_state/view/record | 最终图像真值须真人确认，不能由模型自行提交 |
| 识别记录单条/批量删除、恢复 | workspace_delete_records、workspace_review_record.restore | 具体范围一次批准，保留历史和文件 |
| 单条/批量反馈入池 | business_feedback_add_confirmed、workspace_add_feedback | 仅接受有效人工确认；入池不等于覆盖数据集标签 |
| 回原数据集修订版、反馈单独成集 | business_dataset_feedback_revision、draft_create_from_feedback/assign_splits/finalize；巡检run分组route工具 | 原图匹配后替换修订副本中的对应标签，新图才追加；原正式版本保留 |
| 训练/验证/测试划分、数据整理与候选登记 | business_dataset_split/transform/register_candidate、directory_transform | 新输出走项目目录与正式校验，不以直接改文件代替登记 |
| 文件来源、属性、重复与跨集合重复检查 | business_dataset_inspect_samples | 只读诊断，不自动删除全部重复项；模糊来源不能猜测覆盖 |
| 数据集/模型/草稿删除与恢复 | workspace_manage_resource | 原页面与工具同一依赖检查；在用资源可能被正常拒绝 |
| 增量训练、状态、模型比较、发布与撤销发布 | business_training_start/get_state、model_compare/publish/unpublish | 训练必须指定父模型；模型条件不同不能据此宣称效果变好 |
| PDF/Word解析和知识检索 | business_document_parse/search | 有附件/文档引用可处理，不等于资料库所有管理按钮均已接通 |
| 工作区文件读写与PowerShell | OpenCode原生文件/命令工具 | 已有文件删改、未知影响操作保留批准；不能用Shell/SQL绕过业务权限或直接改数据库 |

## 2. INT-41补齐的管理与界面能力

| 范围 | 当前实现与边界 |
|---|---|
| 项目管理 | workspace_projects/manage_project：创建、改名、说明/要求、首次绑定目录、删除恢复。具体写入需确认；已有目录不直接更换，与人工入口相同 |
| 会话管理 | workspace_sessions/manage_session/switch_context：新建、改名、列表搜索、按offset分页读完整可见历史、显式切换、删除恢复。列表搜索最近200会话；历史仅作材料，不能读其他账号 |
| CSV导出 | workspace_export_records_csv：指定页每页50条，再应用本页搜索/复核状态；输出相同五列、BOM及公式转义，文件在工作区exports中。对话展示鉴权后的下载链接 |
| 资料与原文 | workspace_documents：当前项目资料列表、按块分页读取、打开原文。PDF显示原文件，Word显示解析段落/表格定位并提供原件下载；不是Word排版编辑器 |
| 任务手册 | workspace_manuals/manage_manual：列表、读取、创建/更新个人手册、为本人会话选择固定版本。内置只读；当前任务不随手册更新悄悄换版本 |
| 固定界面命令 | workspace_ui：主题、业务页助手右侧栏、对话顶部/最新、复制本会话消息、设置入口及重播引导。不是任意浏览器脚本、所有下拉框或自动授权器 |

## 3. 应保留本人操作的配置和决定

- API Key保存/删除、更换模型连接：本人配置入口，密钥不能作为普通聊天参数交给模型。
- MCP新连接配置、通用目录授权、只读工具放行和权限模式扩大：由本人设置。项目首次绑定目录可由Agent准备，必须由本机管理员确认具体目标；不能自动批准或更换已有绑定。
- 最终人工标注真值与删除批准：Agent可以准备具体改动；最终决定仍须本人确认，不伪造人工身份。

## 4. 不能扩大解读的范围

- 当前已接入的训练是**从父模型继续的增量训练**，不是从零初始训练的完整通用入口；training.start明确不支持运行中取消。已有“停止Agent任务”不等于终止正在运行的GPU训练。
- 旧后端的视频、实时巡检接口不在这轮图片Agent闭环的已接入清单中；当前web-haixun主导航也没有这些流程页面。
- 文件存在或文件已修改，不代表业务数据库、已登记ZIP和模型关联自动同步；必须通过相应业务工具导入或生成版本。
- 接口覆盖不保证任意模型、数据规模和本机硬件均已真实验收；不把隔离测试冒充成真实付费模型和训练验收。
