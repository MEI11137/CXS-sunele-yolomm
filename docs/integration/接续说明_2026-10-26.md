# 海巡智检 V1 接续说明

本轮由 Codex 接着 WorkBuddy 的 INT-08 与未提交 INT-09 开发，修改仍在 `integration/haixun-v1`。原未提交代码已备份在工作区的 `操作备份/Codex接续海巡智检v1_20261026/`。

## 本轮可使用的入口

- 右侧巡检助手：历史任务、工具过程、计划确认、逐项动作确认/拒绝、停止、跳转人工页面和状态续接。
- 识别记录/人工复核：真实 AI/人工/回流状态；类别跟随记录的训练数据集，无缺陷状态正确保存。
- 数据集：反馈生成草稿、人工划分、定稿；模型管理：导入权重、增量训练和刷新真实状态。
- 扩展与连接：本人 MCP 配置、stdio/Streamable HTTP 发现、逐工具只读放行和撤销；本人项目目录授权和撤销。
- 资料与手册：PDF/DOCX 上传解析、按项目检索和原文定位；手册任务使用锁定版本。
- 文件候选：显式合并原数据和人工确认反馈；保留原数据，校验冲突与输入变化，不覆盖源文件。

## 启动

使用原来已经能运行 YOLO 的 Python 环境。后端目录：`CXSDet-YOLOmm/CXSDet/web-flask`。

```powershell
python -m pip install -r requirements-agent.txt
python app.py
```

同一数据库只启动一个后端。旧进程要先正常关闭，再启动新代码；不要同时起两个进程来“刷新”。后端默认 5020。

前端目录：`CXSDet-YOLOmm/CXSDet/web-haixun`。

```powershell
npm ci
npm run dev
```

默认访问 `http://127.0.0.1:5173`。前端通过同源 `/api` 代理访问 5020；需要其他后端端口时，用 `VITE_BACKEND_ORIGIN` 设置开发代理。此变量是地址，不是 API Key。

登录并选择工作区，在设置里填个人大模型连接。Key 只放在设置的密钥字段，不放聊天、源码或截图。MCP 另用自己的凭据，不能复用站点的大模型 Key。

## 复验

```powershell
# 后端；建议通过 DB_PATH / FILE_STORE_PATH / FLASK_TEMP_DIR 指向独立测试目录
python -m pytest tests -q -p no:cacheprovider

# 前端
npm run build
```

MCP 协议用例会在回环地址启动测试 echo 服务，不连接大模型。真实大模型与 GPU 训练演示仍需自己的连接和训练数据；测试记录不能代替真实效果指标。
